# Brand Guide — easy-pokedex-v2

レトロ携帯ゲーム機の図鑑をオマージュした、ドット／ピクセル調の Pokédex Web アプリのブランドガイドです。トーン＆マナー、ロゴ利用規定、カラールール、タイポグラフィを定めます。

すべての色・フォント・余白は `apps/web/src/styles/tokens.css` のデザイントークンを単一ソースとします。本書は実際に実装されたトークン名・アセットパスを参照しており、これらを直接参照すれば同じ見た目を再現できます。

- デザイントークン: `apps/web/src/styles/tokens.css`
- フォント定義: `apps/web/src/styles/fonts.css`
- グローバルスタイル（世界観の地の部分）: `apps/web/src/styles.css`
- ロゴコンポーネント: `apps/web/src/app/shared/icon/logo.ts`
- ロゴマーク SVG: `apps/web/public/icons/logo-mark.svg`
- アプリアイコン SVG: `apps/web/public/icons/app-icon.svg`
- UI アイコン定義: `apps/web/src/app/shared/icon/icon-defs.ts`

## 1. トーン＆マナー

### 世界観

初代携帯ゲーム機（DMG 期）の図鑑をオマージュした、ドット／ピクセル調の世界観を中心に据えます。プラスチック筐体のベゼルに囲まれた、緑がかったモノクロ液晶（LCD）の画面に図鑑が映っている、という見立てです。

- モチーフ: 携帯機の筐体（ベゼル）＋ドットマトリクス液晶画面＋赤い電源 LED。
- 質感: ハードエッジなドット、ブラーのないオフセット影、8px グリッドに整列したレイアウト。
- 配色の地: 緑がかった液晶（lit panel）を基調とするライトテーマ。

### 喚起する感情

- 懐かしさ: 旧世代の携帯機を触っていた記憶を呼び起こす。
- 遊び心: 図鑑を「気軽に」めくる軽快さ。深刻さや高級感ではなく親しみやすさ。
- 端末を握っている感覚: 画面・ベゼル・電源 LED の見立てで「機械を操作している」手触りを演出する。

### やること・やらないこと

- やること
  - ピクセル／ドットの規則性を保つ。図形はドットグリッド上で整数座標に置く。
  - 動きは `--easing-step`（`steps(4, end)`）でフレーム送りの軽快さを出す。
  - 余白は `--space-*`（8px グリッド）に揃える。
- やらないこと
  - Inter / Roboto などの汎用サンセリフに寄せない。ピクセル／ドット系フォントを使う。
  - グラデーションやソフトシャドウで「今風のフラット UI」にしない。影はブラーなしのドット影（`--shadow-dot-*`）に限る。
  - 角丸を大きく取らない。半径はドット調の小さな値（`--radius-*`）に留める。
  - 写実的・実写的なビジュアルを持ち込まない。

## 2. ロゴ利用規定

ロゴは「ドット調の Poké Ball マーク」＋「ピクセル表示フォントのワードマーク」を横並びにした構成です。アプリ内のロゴは `app-logo` コンポーネント（`apps/web/src/app/shared/icon/logo.ts`）として実装され、マークをインライン SVG で内包し、ワードマークを `--font-display` で表示します。

- マーク単体（参照用）: `apps/web/public/icons/logo-mark.svg` — 16×16 のドットグリッドで描いた Poké Ball マーク（ベゼルなし）。
- ワードマーク文言: `app-logo` の `label` 入力で渡す。ヘッダーは選択ロケールの `app.title`（`messages()['app.title']`）を渡すため、ワードマークはロケール依存で表示される（en: "Easy Pokédex" / ja: "イージーポケモン図鑑"。`apps/web/src/app/i18n/messages.ts`）。

### マークの構造

`logo.ts` の SVG は次の 3 塗り分けで構成されます（クラス名はトークンを参照）。

- `.logo__ink` / `ink`: `--lcd-3`（最暗のドットインク）— 外周リングと赤道帯。
- `.logo__lit` / `lit`: `--lcd-0`（点灯パネル）— 上下半球の明部。
- `.logo__led` / `led`: `--led-power`（赤い電源 LED）— 中央ボタンのコア。

スタンドアロンの SVG（`logo-mark.svg` / `app-icon.svg`）は上記 3 塗りに加え、`.mid`: `--lcd-1`（中間グリーン）を薄いドットの陰影として持ちます（計 4 塗り）。

### クリアスペース（余白）

ロゴの周囲には、マークの 1 ドット分（マーク全体を 16 等分した 1 マス）以上のクリアスペースを確保します。隣接要素・テキスト・画像をこの領域に侵入させません。横並びのマークとワードマークの間隔は `--space-2`（8px）を基準とします（`app-logo` の `.logo` の `gap`）。

### 最小サイズ

ピクセルアートは整数倍でないとエッジがにじみます。

- マーク単体: 16px 四方（= 1 ドット 1px）を最小とし、拡大は整数倍（32px, 48px, 64px …）を推奨します。
- ロゴ全体（マーク＋ワードマーク）: ワードマークが `--font-size-display-md`（14px）を下回らないサイズを最小とします。`app-logo` ではマークがワードマークのフォントサイズに連動して `1.6em` で描画されます。
- 拡大・縮小時は `image-rendering: pixelated` を維持し、ドットがにじむ補間を避けます。

### 配置・背景

- ベゼル上（`--color-shell`）に置く場合は、マークの薄い lit ハロー（`drop-shadow(0 0 1px var(--lcd-0))`、`logo.ts` 参照）で輪郭を確保します。
- 液晶画面上（`--color-screen` / `--lcd-0`）にも置けます。`ink` のコントラストが十分なため判読性は保たれます。

### 禁止例（Don'ts）

- 非整数倍でのリサイズや、`image-rendering` を効かせずに拡大してドットをにじませること。
- マークとワードマークの相対比率・間隔を変更すること。
- 色をトークン外の任意色に置き換えること（塗りは `--lcd-3` / `--lcd-0` / `--led-power` に限る）。
- マークだけを回転・反転・傾斜させること。
- ブラー・ドロップシャドウ（規定の lit ハローを除く）・グラデーション・縁取りを追加すること。
- ワードマークを `--font-display` 以外のフォントに差し替えること。
- クリアスペース内に他要素を重ねること。

## 3. カラールール

色は `tokens.css` の CSS カスタムプロパティを介してのみ使用します。コンポーネントに生のカラーコードを書かず、必ずトークン名を参照します（例: タイプチップは `type-style.ts`（`apps/web/src/app/features/shared/type-style.ts`）が `--type-*` / `--type-*-ink` を引く）。

### 3.1 モノクロ液晶（LCD）ベース

初代携帯機の緑画面に着想した 4 階調のドットマトリクス・ランプです。明（点灯パネル）から暗（ドットインク）へ向かいます。

| トークン  | 値        | 役割                             |
| --------- | --------- | -------------------------------- |
| `--lcd-0` | `#cfe8b0` | 点灯パネル／画面背景（最明）     |
| `--lcd-1` | `#9bbc6c` | 中間グリーン／薄いドット         |
| `--lcd-2` | `#5a7942` | 影のドット／二次インク           |
| `--lcd-3` | `#1b2e1a` | 最暗のドットインク／本文テキスト |

筐体（ベゼル）は液晶を縁取るプラスチックのトーンです。

| トークン      | 値        | 役割                                 |
| ------------- | --------- | ------------------------------------ |
| `--bezel-0`   | `#e6e6ea` | ベゼルのハイライト                   |
| `--bezel-1`   | `#c4c4cc` | ベゼル面                             |
| `--bezel-2`   | `#8a8a93` | ベゼルの影／継ぎ目                   |
| `--bezel-ink` | `#2a2a30` | 筐体に印字されるラベル               |
| `--led-power` | `#d83a3a` | 電源 LED／ステータスアクセント（赤） |

### 3.2 セマンティックロール

UI では生の `--lcd-*` / `--bezel-*` ではなく、原則として以下のロールトークンを参照します。

| ロール                               | 参照先        | 用途                                           |
| ------------------------------------ | ------------- | ---------------------------------------------- |
| `--color-screen` / `--color-surface` | `--lcd-0`     | 画面・面の背景                                 |
| `--color-surface-raised`             | `#dcefc4`     | 画面上に浮くカード                             |
| `--color-shell`                      | `--bezel-1`   | 筐体ベゼル                                     |
| `--color-shell-edge`                 | `--bezel-2`   | 筐体の縁                                       |
| `--color-text`                       | `--lcd-3`     | 液晶上の本文テキスト                           |
| `--color-text-muted`                 | `--lcd-2`     | 補助テキスト（後述の制約あり）                 |
| `--color-text-on-shell`              | `--bezel-ink` | 筐体上のラベル                                 |
| `--color-text-inverse`               | `--lcd-0`     | 暗いドット塗りの上に乗せる明インク             |
| `--color-border`                     | `--lcd-3`     | 既定の枠線                                     |
| `--color-border-soft`                | `--lcd-2`     | 弱い枠線                                       |
| `--color-accent`                     | `--led-power` | アクセント（LED 赤）                           |
| `--color-focus`                      | `#1147d6`     | フォーカスリング（液晶緑に対し高コントラスト） |

使い分けの原則

- 地の面・本文は液晶ベース（`--color-surface` ＋ `--color-text`）を基本とする。
- 赤（`--color-accent` / `--led-power`）は電源 LED 由来のアクセント。多用せず、ステータス・強調の一点に絞る。
- フォーカス可視化は必ず `--color-focus` を使う（青）。液晶緑・赤アクセントに埋もれない高コントラスト色として選定されている。

### 3.3 タイプ別アクセント

ポケモンのタイプ色は 18 種のアクセントで、チップなどのアクセント表現に使います。各タイプは「塗り（`--type-*`）」と「その上に乗せる文字色（`--type-*-ink`）」のペアで定義され、ペアごとに通常テキストで WCAG AA（4.5:1 以上）を満たすよう調整されています。

使用ルール

- タイプ色は必ず塗り＋インクのペアで使う。塗りに `--type-fire` を使うなら、その上のテキストは `--type-fire-ink` を使う（`type-style.ts` の `typeChipStyle()` がこの対応を生成する）。
- タイプ色は液晶ベースに対するアクセント。背景全体や本文色には使わず、チップ・バッジなど局所のアクセントに限定する。
- 18 ペアの一覧は `tokens.css` の `--type-normal` 〜 `--type-fairy` を参照する（例: `--type-water` / `--type-water-ink`、`--type-grass` / `--type-grass-ink`）。

### 3.4 コントラスト（WCAG AA）

レトロ配色でも可読性を担保するため、以下のペアリングを守ります。

- 本文テキスト: `--color-text`（`--lcd-3`）on `--color-surface`（`--lcd-0`）≈ 9.7:1。本文に使う標準ペア。
- 補助テキスト: `--color-text-muted`（`--lcd-2`）on `--lcd-0` ≈ 3.6:1。AA を満たすのは大きい文字（large text）のみ。本文サイズの常用テキストには使わない。
- タイプチップ: 各 `--type-*` 塗り＋対応する `--type-*-ink` は通常テキストで 4.5:1 以上。塗りとインクのペアを崩さない限り AA を満たす。
- フォーカスリング: `--color-focus`（青）を液晶緑の上で使い、視認性を確保する。

## 4. タイポグラフィ

ピクセル／ドット系フォントで世界観を統一します。汎用サンセリフ（Inter / Roboto 等）は使いません。フォントは `@fontsource` でセルフホストし（`apps/web/src/styles/fonts.css`）、ランタイムで外部 CDN を叩きません。

### フォントファミリ

| トークン         | スタック                                     | 用途                                                                 |
| ---------------- | -------------------------------------------- | -------------------------------------------------------------------- |
| `--font-display` | `'Press Start 2P', 'DotGothic16', monospace` | 見出し・図鑑のクローム（ナビ・ラベル・チップ・ボタン・ワードマーク） |
| `--font-body`    | `'VT323', 'DotGothic16', monospace`          | 本文・読ませるテキスト                                               |
| `--font-mono`    | `'VT323', 'DotGothic16', monospace`          | 等幅用途（本文と同系）                                               |

- Press Start 2P: 見出し用の真正ピクセルフォント（latin）。
- VT323: 背の高いドットマトリクス端末フォント（latin）。本文の判読性を確保。
- DotGothic16: 日本語（かな・漢字）のドットフォント。ja ロケールでもピクセル感を保ち、汎用サンセリフに落ちないようフォールバックに据える。

### タイプスケール

ピクセルフォントは小さく描画されるため、本文（VT323）は大きめに設定します。スケールは 8px 整列の base に根ざします。

ディスプレイ（見出し・クローム、`--font-display`）

| トークン                 | 値                | 用途                           |
| ------------------------ | ----------------- | ------------------------------ |
| `--font-size-display-xl` | `1.75rem` (28px)  | 画面タイトル（`h1`）           |
| `--font-size-display-lg` | `1.25rem` (20px)  | セクション見出し（`h2`）       |
| `--font-size-display-md` | `0.875rem` (14px) | ラベル・チップ（`h3`）         |
| `--font-size-display-sm` | `0.625rem` (10px) | クロームの細字（ナビ・ボタン） |

ボディ（本文、`--font-body`）

| トークン              | 値               | 用途                 |
| --------------------- | ---------------- | -------------------- |
| `--font-size-body-lg` | `1.5rem` (24px)  | 大きめ本文           |
| `--font-size-body-md` | `1.25rem` (20px) | 既定の本文（`body`） |
| `--font-size-body-sm` | `1rem` (16px)    | 小さめ本文           |

行間・字間

| トークン                   | 値       | 用途                                                     |
| -------------------------- | -------- | -------------------------------------------------------- |
| `--line-height-display`    | `1.4`    | 見出しの行間                                             |
| `--line-height-body`       | `1.3`    | 本文の行間                                               |
| `--letter-spacing-display` | `0.04em` | ディスプレイフォントの字間（ピクセル字形の詰まりを緩和） |

使用ルール

- 見出し・UI クローム（ナビ・ボタン・チップ・ラベル・ワードマーク）は `--font-display` と表示スケールを使う。`--letter-spacing-display` を併用する。
- 読ませる本文は `--font-body` とボディスケールを使う。display スケールを本文に転用しない。
- 10px の `--font-size-display-sm` は短いクローム文言（ナビ・ボタンラベル）に限定し、長文には使わない。

## 5. ドット調アイコン

UI アイコンは 16×16 のドットグリッド上で矩形塗りとして描いたインライン SVG です（`shape-rendering="crispEdges"`、`image-rendering: pixelated`）。塗りは `currentColor` を使うため、配置先のフォント色トークンがそのまま反映されます。

- 定義: `apps/web/src/app/shared/icon/icon-defs.ts`（`ICON_PATHS`）
- 描画: `app-icon` コンポーネント（`apps/web/src/app/shared/icon/icon.ts`）
- 現在のアイコン: `globe`（言語切替）, `search`（検索）, `filter`（絞り込み）, `chevron-right` / `chevron-left`（ナビ）, `close`（リセット／クリア）

新しいアイコンを足すときは、16×16 グリッド上の矩形パスとして `ICON_PATHS` にキーとパスを追加します。

## 6. モーション・形状トークン

世界観を支える形状・動きのトークンです（詳細は `tokens.css`）。

- 角丸: `--radius-pixel`(2px) / `--radius-chip`(4px) / `--radius-panel`(8px) / `--radius-screen`(12px、液晶窓の角)。ピクセルアートに合わせ小さく保つ。
- 枠線: `--border-width-hairline`(1px) / `--border-width-chunky`(2px、既定のドットアウトライン) / `--border-width-frame`(4px、筐体フレーム)。
- 影: `--shadow-dot-sm` / `--shadow-dot-md`（ブラーなしのオフセット・ドット影）、`--shadow-screen-inset`（液晶のインセット）。ソフトシャドウは使わない。
- モーション: `--duration-fast`(80ms) / `--duration-base`(140ms)、`--easing-step`（`steps(4, end)`、フレーム送り）/ `--easing-standard`。`prefers-reduced-motion` 時は duration を 0ms に落とす。
- レイアウト: `--layout-max-width`(1024px)。余白は 8px グリッドの `--space-0` 〜 `--space-8`。
